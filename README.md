## 🌟 المميزات (Features)

*   **🌍 دعم كامل للغتين (Bilingual):** واجهة مستخدم وإنشاء فواتير باللغتين العربية والإنجليزية.
*   **📱 تطبيق ويب تقدمي (PWA):** يعمل اوفلاين ويمكن تثبيته على الموبايل والكمبيوتر.
*   **🧾 التوافق مع ZATCA:** دعم كامل لإنشاء رمز الاستجابة السريع (QR Code) المتوافق مع هيئة الزكاة والضريبة والجمارك السعودية.
*   **📊 دعم ضريبي شامل:** إعدادات ضريبية معدة مسبقاً لـ 18 دولة في الشرق الأوسط وشمال أفريقيا.
*   **📄 تصدير احترافي (PDF):** تحويل فوري للفواتير إلى ملفات PDF عالية الجودة.
*   **🔗 مشاركة سريعة:** مشاركة الفواتير بسهولة عبر الواتساب أو البريد الإلكتروني.
*   **📈 تحليلات وتقارير:** لوحة تحكم ذكية لتتبع الدخل وتصدير البيانات إلى Excel.

## 🚀 التقنيات المستخدمة (Tech Stack)

تم بناء المشروع باستخدام أحدث تقنيات الويب لضمان الأداء والسرعة:

*   **إطار العمل:** [Next.js (App Router)](https://nextjs.org/)
*   **لغة البرمجة:** [TypeScript](https://www.typescriptlang.org/)
*   **التصميم:** [Tailwind CSS](https://tailwindcss.com/) & [Framer Motion](https://www.framer.com/motion/)
*   **التحليلات (Analytics):** [@vercel/analytics](https://vercel.com/analytics)
*   **إدارة الحالة والبيانات:** Supabase (للمصادقة وقواعد البيانات)

## 💻 التشغيل محلياً (Local Development)

لبدء العمل على المشروع في جهازك الخاص، اتبع الخطوات التالية:

1. **نسخ المستودع (Clone):**
   ```bash
   git clone https://github.com/s7so/fawtarni.git
   cd fawtarni
   ```

2. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   # أو
   yarn install
   # أو
   pnpm install
   ```

3. **تشغيل خادم التطوير (Run Development Server):**
   ```bash
   npm run dev
   ```

4. **معاينة المشروع:**
   افتح المتصفح على الرابط [http://localhost:3000](http://localhost:3000).
